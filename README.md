# 📊 Sales Data Analytics & Prediction — Capstone Project

## 📌 Project Overview

This project is an end-to-end Data Analytics Capstone Project focused on analyzing sales performance, identifying business insights, predicting sales, and presenting results through an interactive Power BI dashboard.

The project combines:

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Excel
- Power BI
- Exploratory Data Analysis
- Regression Modeling
- Data Visualization
- Business Intelligence

The main objective is to transform raw sales data into meaningful business insights and build a regression model to predict sales.

---

## 🎯 Project Objectives

The project focuses on the following objectives:

1. Perform Exploratory Data Analysis (EDA) on the sales dataset.
2. Clean and prepare the data for analysis.
3. Analyze sales, profit, products, countries, and customer segments.
4. Identify important business trends and patterns.
5. Build a regression model to predict sales.
6. Evaluate the regression model using appropriate metrics.
7. Create an interactive Power BI dashboard.
8. Present key findings and business recommendations.
9. Compile the complete analysis into a final report.
